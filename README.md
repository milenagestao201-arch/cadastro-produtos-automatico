# 🤖 Bot de Automação de Cadastro de Produtos

Bot desenvolvido em Python que automatiza o cadastro 
de produtos em sistemas web a partir de um arquivo CSV.

## 🚀 Tecnologias utilizadas
- Python
- PyAutoGUI
- Pandas

## ⚙️ Como usar
1. Clone o repositório
2. Instale as dependências:
pip install pyautogui pandas
3. Configure o arquivo `main.py` com seu email e senha
4. Execute o `main.py`

## 📋 Estrutura do CSV
O arquivo `produtos.csv` deve conter as colunas:
codigo, marca, tipo, categoria, preco_unitario, custo, obs
